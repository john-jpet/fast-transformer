# About Dryft's Hack the North Challenge (from the [devpost](https://hackthenorth2026.devpost.com/)):

Dryft is building the future of manufacturing intelligence.

We're giving every team an autoregressive transformer and one goal: make it generate tokens as fast as possible.

How you get there is up to you: write Triton kernels, fuse operations, rethink memory layouts, or build an autoresearch agent that experiments, benchmarks, and discovers optimizations for you.

Submissions will be run on H100s and must pass correctness tests before being benchmarked on hidden workloads.
